アプリ翻訳ファイル チェッカー（Android / iOS / XLIFF）

スマホアプリの文字列ファイルを原文（英語など）と訳文（日本語・中国語など）で突き合わせ、ビルドが落ちる・表示が崩れる・訳し忘れにつながるミスを一覧にします。AI翻訳や機械翻訳の出力をストアに出す前の確認にも使えます。ファイルはブラウザの中だけで処理し、どこにも送信しません。

形式： 訳文の言語コード（.xcstrings 用）：

原文ファイル
.xcstrings と XLIFF は原文側だけに貼れば、ファイル内の訳と比べます。
訳文ファイル

訳文が原文の 倍（表示幅、全角=2）を超えたら注意

未翻訳から除外する語（アプリ名・ブランド名など、カンマ区切り）

チェックする内容

  • キーの過不足：原文にあって訳文にないキー（英語のまま表示される）、訳文にだけある古いキー。
  • プレースホルダ：%1$s %d %@ %lld {name} %%、HTMLタグ（<b>）、\n の数と種類の違い。数がずれるとアプリが落ちることがあります。語順を入れ替えるときは %1$s のような番号つきにします。
  • Android 固有：エスケープされていない '（アポストロフィ）や先頭の @ ?、translatable="false" の文字列の誤訳、plurals の quantity の不足（日本語・中国語は other だけで足ります）。
  • iOS 固有：.strings の書式エラー（セミコロン抜け・閉じていない引用符）、.xcstrings の needs_review・new・stale 状態や訳の抜け、plural / device バリエーションの訳し忘れ。
  • XLIFF：target が空、state が needs-translation / new / initial のまま。
  • 未翻訳の疑い・長すぎる訳：原文と同じ訳、表示幅が原文より大きく長い訳（ボタンやタブで切れやすい）。
このツールは形式上の点検だけをします。訳の自然さ、画面での切れ方は、実機やスクリーンショットで最後に確かめてください。ストア用のスクリーンショットは 多言語キャプション作成、JSON・PO は 翻訳ファイル（JSON/PO）チェッカー、用語の統一は 対訳・用語集チェッカー へ。
翻訳やチェックの作業をまとめて頼みたい方は shinji-work@mail.grokbot.com までどうぞ（日本語・英語・中国語）。
