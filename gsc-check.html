Search Console CSV 改善候補チェッカー

Googleサーチコンソールの「検索パフォーマンス」から書き出したCSVを入れると、手を入れる価値が高いクエリだけを優先度順に並べます。処理はすべてブラウザの中で行われ、データはどこにも送信されません。

書き出し方：サーチコンソール →「検索結果のパフォーマンス」→ 右上「エクスポート」→「CSVをダウンロード」→ ZIPの中の クエリ.csv（英語表示なら Queries.csv）。クエリとページが同じ行にあるCSV（Looker Studio や API で出したもの）なら、共食いチェックもできます。

または下に貼り付け（1行目は見出し）


見ているもの：①あと一歩：平均掲載順位が指定範囲（初期値8〜20位）で表示回数が多いクエリ。1ページ目上位に上がると伸びやすい候補です。②低CTR：順位から見込まれるクリック率の半分未満のクエリ。タイトルと説明文（meta description）の書き直し候補で、「見込みとの差」は取りこぼしているクリック数のおおよその目安です。③共食い：同じクエリで2つ以上のページが表示されている場合（ページ列があるCSVのみ）。④質問型：「とは」「方法」「なぜ」「how」などを含むクエリ。FAQや、AI検索に引用されやすい「最初に答えを書く」段落の候補です。見込みクリック率は一般的な目安（1位約28%、3位約10%、10位約2%）で、業種や検索の種類で大きく変わります。順位やクリックが上がることを約束するものではありません。
