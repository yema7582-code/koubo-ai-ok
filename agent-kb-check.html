AIエージェント向けショップ情報 公開前チェック＆ナレッジ文作成

買い物客が ChatGPT・Gemini・Copilot・Perplexity などに「この店は海外発送する？」「返品は何日以内？」と聞いたとき、AIが正しい答えを返すには、お店側が事実を公開しておく必要があります。Shopify では Sales channels → Agentic → Knowledge base に下書きされた事実は、公開するまでAIに渡りません（旧 Knowledge Base アプリは 2027年1月15日に終了）。BASE・STORES・独自カートでも、FAQ・特商法・配送ページに同じ事実を書いておくと、AI検索と問い合わせ対応の両方に効きます。このツールは、必要な項目の抜けを確認し、公開用のナレッジ文とテスト質問をまとめて作ります。

Shopifyでの公開手順（目安）

  1. 管理画面で Sales channels → Agentic → Knowledge base を開く。
  2. Shopifyがストアから下書きした事実を確認し、違うところを直す。下書きは公開するまでAIに渡りません。
  3. Returns & warranty・Fulfillment（配送）・Gift services・Payment・Contact・Company policies を優先して公開する。
  4. 下の「テスト質問」を ChatGPT / Gemini などに投げ、答えがナレッジと一致するか確認する。違えばストアページかナレッジを直す。
  5. 旧 Knowledge Base アプリ利用者：追加ファクトが1,000件超の場合は、残したい事実を 2027年1月15日までに新画面へ移す。
公開したナレッジはストアフロントMCP経由で第三者のAIにも読まれ得ます。お客様向けの一般情報だけを載せ、取引先ごとの特別単価や社内メモは書かないでください。このツールは作業の補助であり、Shopifyや各モールの仕様変更・法的助言を保証するものではありません。最新の操作は Shopifyヘルプ（Knowledge base） で確認してください。
