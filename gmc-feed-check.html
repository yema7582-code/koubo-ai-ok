Google Merchant Center／無料リスティング 商品データ否認理由セルフチェック

Googleの無料リスティングやショッピング広告に出す前に、商品フィードの必須属性の抜けと、否認につながりやすいパターンを点検します。Shopify商品CSVの「薄さ」を見る catalog-check とは別で、ここでは Merchant Center の属性名（id・title・gtin など）に沿って確認します。

処理はすべてこのブラウザ内です。フィードは送信されません。結果は自己点検の目安であり、Googleの最終審査や掲載を保証しません。仕様は変わるので、最終確認は 商品データ仕様 と Merchant Center の「要対応」タブで。

列名は英語属性名でも日本語近似でも可（例: 商品ID→id、タイトル→title）。最大500行まで点検します。

よくある否認・警告パターン（このツールが見るもの）

  • 必須属性の欠落：id / title / description / link / image_link / availability / price
  • 識別子：gtin または（mpn＋brand）。どちらも無いのに identifier_exists=yes／空のまま → 否認や配信制限の典型
  • 価格形式：数値＋ISO通貨（日本向けは 1980 JPY）。円マークのみ・カンマ区切りのみは不適
  • availability 値：in_stock / out_of_stock / preorder / backorder 以外
  • URL：http(s) でない、画像がプレースホルダっぽいファイル名
  • タイトル品質：極端に短い／キーワード詰め／全角スペースだらけ／プロモ文言（送料無料・セール中など）
  • 説明文：短すぎる・HTMLタグだらけで本文が取れない・promotional text 過多
  • カテゴリ：google_product_category 未設定（警告寄りだが品質低下）
  • 重複 id：同一フィード内で id が重複
画像上のロゴ／透かし／CTA文字、ランディング価格とフィード価格の不一致、robots.txt によるクロール阻害などは、このページのテキスト点検では検出できません。Merchant Center の診断と実ページ確認が必要です。
