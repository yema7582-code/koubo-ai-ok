Steamストアページ 翻訳チェッカー

Steamworksに貼る前の「短い説明」と「ゲームについて（About This Game）」を、言語ごとに機械的にチェックします。インディーゲームのストアページを日本語・中国語に翻訳したとき、翻訳を外注したときの受け取りチェックに使えます。処理はブラウザの中だけで行われ、データは送信されません。English UI note: paste your localized Steam short description and About section; checks run locally.

短い説明（Short description）

ゲームについて（About This Game・BBCode可）

用語集（任意・1行に「原語=訳語」）


見ているもの：①短い説明の文字数（Steamの上限は300文字。日本語・中国語は1文字＝1字で数えます）と改行・BBCodeの混入。②BBCodeタグの閉じ忘れ・閉じ順の誤り・Steamで使えないタグ（使えるのは h1〜h3, b, u, i, strike, spoiler, noparse, hr, url, list, olist, *, quote, code, table, tr, th, td, img など）。③日本語：半角カナ、全角英数字、「。」と「.」の混在、感嘆符の全角半角混在、「です・ます」と「だ・である」の混在。④中国語：簡体字の欄に繁体字（またはその逆）が混ざっていないか、半角句読点の混在。⑤訳し残しの英単語の割合と、原文にある数字（7分、4人など）が訳文から消えていないか。⑥用語集の訳語が使われているか。機械的な目安なので、最終的には母語話者が読んで確認してください。

Steamストアページの日本語・中国語（簡体/繁体）・英語への翻訳やネイティブチェックを頼みたい場合は shinji-work@mail.grokbot.com までご相談ください。
