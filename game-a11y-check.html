ゲーム向けアクセシビリティ（Xboxガイドライン）公開前チェッカー

Xbox Accessibility Guidelines（XAG、公開版 v3.2）のうち、インディーが公開前に自分で潰せる項目を点検します。入力はブラウザ内だけ（送信なし）。これは公式の認証でも、欧州アクセシビリティ法（EAA）などの法的適合証明でもありません。Webページ用の a11y-check や Steam Deck 互換の steam-deck-check とは別用途です。

1. 視覚（XAG 101 / 102 / 109 / 117 / 118）

本文テキストの高さが目安以上（PC 1080p で約18px以上、据え置きテレビ 1080p で約26px）。メニュー・HUD・通知・エラーも含む
テキストを最大200%まで拡大でき、はみ出しても読める（一方向のスクロールは可。縦横同時スクロールは不可）
装飾フォント以外に、サンセリフ（ゴシック体）の選択肢がある
文字と背景のコントラストがおおむね 4.5:1 以上（重要なHUDも含む）
色だけに頼らない（色覚サポート、または形・アイコン・テキストの併用）
敵・拾う物・目標など重要なオブジェクトが背景から見分けられる
カメラシェイク・モーションブラー・強い画面揺れをオフまたは弱められる
点滅がおおむね秒間3回を超えない。強い点滅があるなら注意表示と低減オプションがある

2. 聴覚（XAG 103 / 104 / 105 / 106）

重要な合図が音だけに依存しない（画面効果やアイコンでも伝わる）
重要な台詞に字幕がある
重要な効果音・話者名・方向の手がかりを字幕やキャプションで示せる
字幕の大きさや背景（不透明度）を変えられる
BGM / ボイス / SE（／チャット）を別々に音量調整できる
メニューを読み上げできる、またはOSのスクリーンリーダーと両立する
メニュー読み上げは対象外（文字が大きく、色とアイコンだけで辿れる単純なUI）

3. 入力とメニュー（XAG 107 / 110 / 112 / 113）

主要な操作をゲーム内でリマップできる（ボタン入れ替えだけでなく、行動への割り当てが理想）
長押し必須の操作に、トグルや自動ホールドの代替がある（または長押しなし）
同時押しや高速連打が必須の箇所に代替がある（または該当なし）
メニューを十字キーや1ボタンずつで辿れる（同時押し不要）
今選んでいる項目がはっきり見える
振動をオフにできる
振動フィードバックは使っていない（上記は該当なし）

4. コミュニケーションと公開情報（EAA隣接・認証ではない）

ボイスチャットしかない場合でも、文字チャットまたは自動字幕の代替がある
ストアページかゲーム内に、字幕・リマップ・色覚・点滅注意などのアクセシビリティ情報が書いてある
